1. How Background Workers Get Called (Execution Lifecycle)

Celery background tasks follow a Producer-Broker-Consumer pattern. FastAPI acts as the producer, Redis acts as the message broker, and the Celery process acts as the asynchronous consumer.

  • 1. User sends HTTP Request
    User posts a file (e.g. POST /api/v1/photos/upload). FastAPI receives the request in Uvicorn event loop.
  • 2. FastAPI enqueues task asynchronously
    FastAPI calls process_photo.delay(photo_id). Celery serializes task metadata into a JSON payload.
  • 3. Redis receives message in Queue
    The task payload is pushed into Redis (Key: celery list). FastAPI instantly returns HTTP 202 to user (< 30ms).
  • 4. Celery Worker pops and executes task
    The Celery worker process (listening to Redis via BRPOP) pops the task payload and executes heavy image AI embedding computation in background.
Code Example in Yaadein:
# 1. FastAPI Producer (src/api/routes.py)
@app.post("/photos/upload")
async def upload_photo(photo_id: str):
    # Enqueue task without blocking HTTP response
    process_photo.delay(photo_id)
    return {"status": "processing", "photo_id": photo_id}

# 2. Celery Consumer (src/workers/app.py)
@celery_app.task(name="process_photo")
def process_photo(photo_id: str):
    # Heavy face detection & pgvector embeddings
    generate_embeddings(photo_id)

Single Server (Co-located)

FastAPI, Celery, Redis, and PostgreSQL run as individual processes/containers inside one EC2 instance.

  • 100% Free: Uses ~720 hrs/month (Fits in 750h AWS Free Tier quota).
  • Low Latency: In-memory IPC / Docker internal bridge networking (0.1ms broker ping).
  • RAM Management: Requires 2GB Swap Space to prevent Out-Of-Memory (OOM) crashes on 1GB RAM micro instances.
  • CPU Sharing: High worker CPU spikes can briefly slow web request handling if worker concurrency isn't capped.
🌐

Decoupled (Multi-Server)

FastAPI runs on Server A, Celery Workers on Server B, Redis & PostgreSQL on managed cloud hosts/Server C.

  • Incurs AWS Costs: 2 EC2 instances = 1,440 hours/month (Exceeds Free Tier by 690 hours -> 💸 Billed!).
  • Independent Auto-scaling: Spin up 10 worker nodes dynamically when queue depth increases.
  • Zero CPU Contention: Web requests never slow down even during intensive video/AI encoding.
  • Network Overhead: All broker messages traverse external TCP/IP network.
